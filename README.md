## Возможности

Repair Management System предоставляет полный цикл управления заявками на ремонт:

- **Система пользователей** — Регистрация и авторизация с ролями `CLIENT` и `MASTER`, изоляция данных
- **Управление заявками** — Создание карточек с типом устройства, моделью, серийным номером и описанием поломки
- **Статусы ремонта** — Автоматический переход по цепочке (новая → диагностика → в ремонте → ожидание запчастей → готова → выдана)
- **Технические заметки** — Ведение записей о выполненных работах и использованных запчастях
- **Финансовый учёт** — Указание итоговой стоимости ремонта для каждой заявки
- **Поиск и фильтрация** — Быстрый поиск по ФИО клиента, модели устройства или серийному номеру
- **Цветовая индикация** — Визуальное отображение статуса заявки в таблице (синий, жёлтый, зелёный, красный)
- **Удаление заявок** — Возможность удалить выполненную или отменённую заявку из системы

## Использование

### Начало работы

При первом запуске авторизуйтесь как мастер (логин: `master`, пароль: `master`) или зарегистрируйтесь как новый клиент. После входа откроется рабочее пространство с боковым меню и списком заявок.

### Основные функции (боковое меню)

| Раздел | Описание |
|--------|----------|
| **Новая заявка** | Форма создания заявки на ремонт (доступно клиенту и мастеру) |
| **Все заявки** | Таблица заявок с цветовой индикацией статуса, поиском и кнопкой удаления |
| **Детали заявки** | Открывается по двойному клику: две вкладки — Информация и Ремонт (редактирование только для мастера) |

### Работа с данными

- Двойной клик по строке заявки открывает детальную карточку с полной информацией
- Клиент видит **только свои** заявки, мастер — **все** заявки в системе
- Мастер может изменять статус, добавлять заметки и указывать стоимость ремонта
- Все изменения сохраняются автоматически в базу данных SQLite
- Поиск работает по ФИО клиента, модели устройства или серийному номеру

## Разработка и тестирование

Проект построен на архитектуре **MVC** с чётким разделением:

- **Модели:** `User`, `RepairRequest`, `Role`, `Status`
